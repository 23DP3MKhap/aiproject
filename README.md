Requirements (Step by step with terminal in project root directory):
- Python (https://www.python.org/downloads/release/pymanager-264/)
- virtual enviorment .venv (python -m venv env)
- activate env (env\Scripts\activate)
Make sure that u got "(env)" at the beggining of ur terminal working directory
- pandas lib (pip install pandas) 
- scikit-learn (pip install -U scikit-learn)
